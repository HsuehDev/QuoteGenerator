# 修復報價單匯出功能

## 問題分析

從 PDF 輸出結果來看，只顯示了報價單最底部的一小部分內容（應付總額、DELVEDRILL TECH），大部分內容都沒有被捕獲。

**關鍵發現**：對比 remote 版本（正常工作的版本）和本地版本，發現關鍵差異：

**Remote 版本（正常）使用**：
- `windowWidth: element.scrollWidth`
- `windowHeight: element.scrollHeight`
- `letterRendering: true`
- 簡單的 `renderElementToCanvas`，沒有複雜的樣式設置

**本地版本（有問題）使用**：
- `scrollX: -window.scrollX, scrollY: -window.scrollY`（移除了 windowWidth/windowHeight）
- 移除了 `letterRendering`
- 添加了複雜的樣式設置和父元素遍歷邏輯

**問題根源**：移除 `windowWidth` 和 `windowHeight` 參數導致 html2canvas 無法正確計算元素尺寸，只捕獲了視窗可見部分。

## 解決方案

### 1. 恢復 windowWidth/windowHeight 參數

修改 `renderWithHtml2Canvas` 函數（[src/utils/exportHandler.ts](src/utils/exportHandler.ts)）：
- **恢復** `windowWidth: element.scrollWidth` 和 `windowHeight: element.scrollHeight`
- **移除** `scrollX` 和 `scrollY` 參數
- **恢復** `letterRendering: true`

### 2. 簡化 renderElementToCanvas

修改 `renderElementToCanvas` 函數（[src/utils/exportHandler.ts](src/utils/exportHandler.ts)）：
- **移除**複雜的樣式保存和恢復邏輯
- **移除** `overflow` 和 `position` 的設置
- **移除** DOM 更新等待
- 恢復到 remote 版本的簡單實現

### 3. 簡化 onclone 邏輯

修改 `onclone` 回調（[src/utils/exportHandler.ts](src/utils/exportHandler.ts)）：
- **移除**複雜的父元素遍歷和樣式設置
- **移除** `position: relative`, `top: 0`, `left: 0`, `margin: 0` 等設置
- **移除** flex/grid 容器的特殊處理
- 恢復到 remote 版本的簡單實現

### 4. 保留必要的改進

保留以下改進（這些是合理的）：
- `replaceFormControlsWithText` 中的樣式保留邏輯（確保布局不偏移）
- PDF 匯出中的 scale 處理（正確處理 scale: 2）

## 實施步驟

1. 恢復 `windowWidth` 和 `windowHeight` 參數
2. 恢復 `letterRendering: true`
3. 移除 `scrollX` 和 `scrollY` 參數
4. 簡化 `renderElementToCanvas` 函數
5. 簡化 `onclone` 邏輯
6. 測試並驗證修復效果
